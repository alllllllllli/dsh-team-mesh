## 取值口径（先看这条，否则"关"可能写错）

环境变量是字符串，代码用两个对称的解析函数（`src/server.js:130-151`）：

| 含义 | 认哪些写法 | 其余怎么写 | 适用 |
| --- | --- | --- | --- |
| **关** | `0` / `false` / `off` / `no`（trim + 小写） | 不认 → 视为"没设" | `BLOB_GC` / `AUDIT` / `RATE_LIMIT` 这类"默认开、可关"的开关 |
| **开** | `1` / `true` / `yes` / `on`（trim + 小写） | 不认 → 视为关（fail-closed） | `ALLOW_UNVERIFIED_ADOPT` 这类"默认关、显式放行"的开关 |

数字类配置按「显式参数 > 环境变量 > 代码默认」读取（`src/server.js:177-184` `pickNumber`）：
**非数字/空值一律回落默认**，不报错、不取 0。个别项额外夹取值（见各行备注）。

## 一、插件 config（写进 DSH profile 的插件配置；`apply(ctx, config)` 读取）

## 五、改开关时的三个硬提醒

1. **板服务 env 生效要重启进程**（`src/server.js` 是启动期一次解析），改文件不重启等于没改。
2. **`dispatcherSessions` 填的是总管会话 id**（不是 instance id）；填错等于谁都不命中，功能静默不启用。
3. **`DSH_TEAM_BOARD_ALLOW_UNVERIFIED_ADOPT` 是"放行未验证"**：默认严格是有意为之，
   打开前先确认"接受跨机/无法验 pid 的接管"这一业务风险，并知道审计里会留下 `unverified=true`。
